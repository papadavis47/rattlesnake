Small exercises to get you used to reading and writing [Python](https://www.python.org) code - _Recommended in parallel to reading [the official Python tutorial](https://docs.python.org/3/tutorial/) 📚️_

## Quick start

```bash
# Installation (requires Rust and uv)
git clone https://github.com/papadavis47/rattlesnake.git
cargo install --path rattlesnake
# Initialization
rattlesnake init
# Moving into new directory
cd rattlesnake
# Starting Rattlesnake
rattlesnake
```

Visit the [**setup**](@/setup/index.md) page for more details 🧰
